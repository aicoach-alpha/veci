# Attribution and project independence

VeCI is an independent OpenWrt administration-interface project maintained at:

- https://github.com/aicoach-alpha/veci

## MoCI research / ancestry

The project began after studying the MIT-licensed **MoCI — Modern Configuration Interface for OpenWrt** repository by HudsonGraeme and the related public OpenWrt forum discussion.

The first VeCI repository import used the MoCI development tree as an engineering reference and preserved that history. VeCI has since replaced the active application shell, routing structure, page modules, visual system, browser authentication handling, rpcd helper, ACL boundary, build script and package layout with VeCI-owned implementations.

Where code remains derived from MIT-licensed upstream material, the MIT terms continue to apply.

Upstream project:

- https://github.com/HudsonGraeme/MoCI

## CoachAssist design relationship

VeCI uses the same in-house visual design language as CoachAssist / vervue.my.id: blue brand accents, light information surfaces and a dark navy navigation system. VeCI does not include CoachAssist application logic or user data.
